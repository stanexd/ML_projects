# Проект1: Реализация KNN и подбор гиперпараметров

В данном проекте реализованы следующие компоненты:

- **Класс для алгоритма K-Nearest Neighbors (KNN)**:
  - Реализация с нуля.
  - Поддержка многоклассовой классификации.

- **Класс для подсчета метрик**:
  - Расчет стандартных метрик классификации, таких как точность, полнота, F1-score и другие.

- **Подбор гиперпараметров**:
  - Выполнена кросс-валидация для оптимизации параметров KNN:
    - Вручную.
    - С использованием `GridSearchCV` из библиотеки `sklearn`.

- **Сравнение с библиотечными алгоритмами**:
  - Сравнение реализованного KNN с методами для многоклассовой классификации из `sklearn`.

### Задача
Распознавание цифр на изображениях на базе набора данных SVHN.

### Особенности
- Реализация "с нуля" позволяет лучше понять внутренние процессы работы KNN.
- Сравнение с готовыми библиотечными решениями подчеркивает производительность и точность собственной реализации.

## Технические особенности

Данный проект был реализован в Google Colab, в связи с чем файл `Project_KNN.ipynb` рекомендуется открывать именно там.
Для открытия файла `Project_KNN.ipynb` в Google Colab, выполните следующие шаги:

1. Перейдите по ссылке: [Google Colab](https://colab.research.google.com/).
2. Выберите "File" -> "Open notebook".
3. Перейдите на вкладку "GitHub" и введите URL этого репозитория.
4. Найдите и выберите файл `Project_KNN.ipynb`.

Теперь вы можете выполнять и редактировать ноутбук прямо в Google Colab.


## Структура проекта

- `Project_KNN.ipynb`: Jupyter Notebook с процессом реализации, подбора гиперпараметров и сравнения.
- `src/`: Папка с вспомогательными файлами, участвующими в проекте.
  - `metrics.py`: Класс для подсчета метрик классификации.
  - `dataset.py`: Методы для загрузки датасета в ноутбук.
  - `knn.py`: Реализация алгоритма KNN с нуля.
  - `download_data.sh`: Скрипт для загрузки структуры Matlab ".mat" на удаленный сервер Google Colab.
- `data/`: Папка с данными.
  - `train_32x32.mat`: Тренировочный датасет.
  - `test_32x32.mat`: Тестовый датасет.
